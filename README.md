# 🛠️ Java Multi-Utility Terminal Application

A robust, menu-driven console application built entirely in Java. This project follows a clean, modular architecture, integrating various daily utility tools into a single, cohesive program. 

## 🌟 Modules Included

This Terminal program consists of 7 independent modules managed through a central unified menu:

* **🖩 Calculator:** Performs fundamental mathematical operations with precise logic.
* **📅 Calendar:** Displays dates and manages events/holidays using file reading operations.
* **🎵 Music Player:** Fully functional audio playback handling `.wav` streams (features tracks like *Narayan.wav* and *Har Har Sambhu.wav*).
* **📝 Notepad:** Create, read, and save text files seamlessly to the local system.
* **👥 People Information:** A mini contact management system utilizing persistent file storage.
* **🔄 Unit Converter:** Fast and accurate conversion between various units.
* **🎮 Game:** An interactive, logic-based mini-game.

## 🚀 Technical Highlights

* **Core Language:** Java 
* **Architecture:** Modular, scalable, and highly organized folder structure.
* **Key Concepts Applied:** * Object-Oriented Programming (OOP)
    * Advanced File Handling (`java.io`)
    * Audio Input Stream processing (`javax.sound.sampled`)

## 💻 How to Run

1. Clone this repository to your local machine:
   > `git clone https://github.com/natwar08-a108y/JavaUtilityApps.git`
2. Open the project in your preferred IDE (e.g., IntelliJ IDEA).
3. Navigate to `src/main/Main.java`.
4. Run the `Main.java` file to launch the central menu and select your desired utility.
